# 커리큘럼 설계

담당: `jazz-curriculum-architect` · `learning-scientist`

## 설계 전제

악기 연주 학습은 **선언적 지식이 아니라 운동 기능 + 청각 패턴 인식의 획득**이다.
따라서 이 커리큘럼의 단위는 "읽은 챕터"가 아니라 **"12키에서 목표 템포로 칠 수 있게 된 것"** 이다.

## 계열화 원칙 (Non-negotiable)

1. **가이드 톤이 먼저다.** 스케일 나열보다 3음·7음의 성부 진행이 항상 앞선다.
2. **셸 → 루트리스 → 확장** 순서를 건너뛰지 않는다.
3. **블루스를 L1 에 배치한다.** 12마디는 폼 감각과 즉흥 진입의 최단 경로다.
4. **코드 스케일(L3)은 손이 이미 아는 소리에 이름을 붙이는 단계다.**
   L1–L2 에서 손이 겪지 않은 소리를 L3 에서 이론으로 먼저 가르치지 않는다.
5. 모든 모듈은 선수 모듈을 `requires` 로 명시하고, 순환 의존이 없어야 한다
   (테스트가 강제).

## 주리(Jury) 기준 작성법

"이해한다"는 **금지어**다. 통과 기준은 반드시
**관측 가능한 연주 행동 + 템포 + 키 범위**로 쓴다.
자동 테스트가 `이해한다 / 익숙해진다 / 친숙해진다 / 느껴본다` 를 잡아내 빌드를 실패시킨다.

나쁨
> ii‑V‑I 진행을 이해한다.

좋음
> ♩=100 에서 12키 전부 ii‑V‑I 을 루트리스 A/B 교대로, 코드 간 성부 이동이
> 대부분 2도 이내가 되게 연주한다.

## 학습과학 적용

### 간격 반복은 "치는 것"에 건다
플래시카드가 아니라 **12키 순환 드릴의 재등장 간격**을 스케줄한다.
복습 간격: 1 → 2 → 4 → 8 → 16 → 30일. 실패하면 1일로 되돌린다.

### 숙련 판정 3요소 (동시 충족)
| 요소 | 가중치 | 왜 |
|---|---|---|
| 목표 템포 도달 | 50% | 느리게만 되는 것은 아직 안 되는 것 |
| 무오류 비율 | 30% | 틀리면서 빨라지는 것은 퇴보 |
| **날짜가 다른 세션의 재현** | 20% | 하루 몰아치기로 통과할 수 없게 |

### 인터리빙 > 블록 연습
한 키를 20분 연속보다 4키를 5분씩 섞는 편이 전이가 좋다.
세션 생성기(`buildSession`)가 같은 드릴이 연속되지 않도록 라운드로빈으로 섞는다.

### 인지 부하 상한
한 모듈이 동시에 요구하는 새 정보는 최대 3덩어리.
초과하면 모듈을 분할한다.

### 데스루프 방지
3회 연속 실패 시 UI 가 난이도 하향을 권고한다:
> 3회 연속 실패했습니다. 템포를 10~15 BPM 낮추고 한 키만 다시 잡으세요.
> 같은 벽에 계속 부딪히는 것은 연습이 아닙니다.

### 스트릭은 단독으로 쓰지 않는다
연속 접속 스트릭만 강조하면 죄책감 설계가 된다.
항상 **누적 연습 분(minute)** 과 병기한다.

## 버클리 정렬

각 레벨의 `berkleeAlignment` 는 대응 과정 **계열**을 표기한다
(Harmony 1–4, Ear Training 1–4, Jazz Keyboard Harmony, Improvisation, Arranging 등).
존재하지 않는 과목 코드를 지어내지 않으며, 정렬은 승인이 아니다.
