# PRD — Jazzytory v1

담당: `product-strategist` · 최종 갱신 2026-09

## 1. 문제

재즈피아노를 시작하는 클래식 전공자·취미 연주자의 이탈 지점은 놀랍도록 일정하다.

1. **코드 심볼 앞에서 멈춘다.** 음표가 없으면 손이 움직이지 않는다.
2. **이론서를 읽지만 손은 늘지 않는다.** 선언적 지식과 운동 기능의 간극.
3. **무엇부터 해야 할지 모른다.** 유튜브 강의는 많지만 순서가 없다.
4. **자기 연주를 평가할 기준이 없다.** "이 정도면 되나?"에 답할 사람이 없다.

시중 해법의 한계
- 교재: 순서는 있으나 소리가 없고 피드백이 없다
- 유튜브: 소리는 있으나 계열성이 없다
- 앱(iReal Pro 등): 반주는 훌륭하나 **무엇을 연습할지 가르치지 않는다**
- 레슨: 가장 효과적이나 비싸고 접근성이 낮다

**Jazzytory 의 자리**: 대학 커리큘럼의 계열성 + 앱의 즉시성 + 교재의 근거.

## 2. 페르소나

### 지민 (주 타깃) — 27세, 직장인, 피아노 12년(체르니 100 수준에서 중단)
- 코드 심볼을 모른다. `C-7` 을 보면 "C 마이너인가?" 정도
- 주 3~4회, 회당 40분 정도 연습 가능
- 목표: "재즈바에서 스탠다드 한 곡을 멋지게 치기"
- **좌절 지점**: 유튜브 강의를 봐도 다음에 뭘 볼지 모른다. 3개월 뒤 제자리

### 현우 (부 타깃) — 19세, 실용음악과 입시생
- 코드는 안다. 보이싱이 빈약하고 솔로가 스케일 나열이다
- 목표: 입시 실기와 잼 세션
- **좌절 지점**: 체계 없이 릭만 모은다

### 서연 (부 타깃) — 41세, 클래식 피아노 강사
- 테크닉은 충분. 즉흥이 두렵다
- 목표: 학생에게 재즈를 가르칠 수 있을 정도

## 3. North Star Metric

> **주간 활성 학습자 중 "리드시트를 열고 30분 이상 연습 기록을 남긴 세션" 비율**

보조 지표
- 배치고사 완료 → 첫 모듈 드릴 기록까지의 전환율
- 드릴의 **날짜가 다른** 재현 세션 비율 (진짜 학습의 대리 지표)
- L1 → L2 승급률 (첫 큰 벽)
- 필청 앨범 "들었음" 표시 수

## 4. 유저 스토리와 수용 기준

| # | 스토리 | 수용 기준 |
|---|---|---|
| US-1 | 초심자로서 어디서 시작할지 알고 싶다 | 배치고사 20문항 이내 완료, 레벨 자동 배정, 첫 모듈로 1클릭 |
| US-2 | 코드 심볼이 무슨 소리인지 즉시 보고 싶다 | 임의 심볼 입력 → 건반 표시 + 발음 + 코드스케일 + 근거, 1초 이내 |
| US-3 | 보이싱을 12키로 연습하고 싶다 | 진행 입력 → 보이싱 10종 · 12키 이조 · A/B 자동 교대 · 자동 키 전환 |
| US-4 | 반주에 맞춰 연습하고 싶다 | 임의 진행·곡에 워킹베이스+컴핑+드럼, 템포/스윙/파트 on-off |
| US-5 | 내가 늘고 있는지 알고 싶다 | 8축 레이더, 드릴별 숙련도, 레벨 목표 대비 표시 |
| US-6 | 무엇을 들어야 할지 알고 싶다 | 앨범별 트랙 단위 청취 지시문, 모듈 연결 |
| US-7 | 이 내용이 믿을 만한지 알고 싶다 | 모든 개념에 출처, 모듈별 검수 상태·루브릭·의견 공개 |

## 5. v1 범위

**포함**
전체 9레벨 커리큘럼 · 이론 엔진 · 보이싱 랩 · 플레이어롱 · 청음 훈련 ·
리드시트 뷰어 · 필청 라이브러리 · 영상 큐레이션 · 진도 추적 · 배치고사 · 검수 대시보드

**비범위 (Out of scope)**
- 계정·로그인·서버 (v1 은 100% 클라이언트, 진도는 localStorage)
- 결제·구독
- MIDI 입력 채점 (v2 후보 — 가장 가치 높은 다음 단계)
- 사용자 간 커뮤니티·공유
- 모바일 네이티브 앱
- 악보 이미지 업로드·OCR

## 6. 기능 우선순위 원칙

모든 기능 제안에 묻는다:

> **"이건 아는 것을 늘리나, 할 수 있는 것을 늘리나?"**

아는 것만 늘리는 기능은 후순위. 범위를 넓히기보다 핵심 루프를 깊게 만든다.

**핵심 루프**: 배치고사 → 오늘의 연습 → 모듈 학습 → 랩에서 손으로 확인 → 진도 기록
